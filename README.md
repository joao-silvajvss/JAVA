# ☕ Estudos e Práticas em Java

Repositório dedicado ao armazenamento de exercícios, algoritmos de lógica e conceitos de Orientação a Objetos em Java, desenvolvidos na **faculdade, cursos complementares e estudos autônomos**.

---

### 📂 Estrutura do Repositório

- **`/01-logica-e-sintaxe`**: Variáveis, operadores, estruturas condicionais (`if/else`, `switch-case`) e laços (`for`, `while`).
- **`/02-orientacao-a-objetos`**: Classes, objetos, métodos, construtores, encapsulamento (`getters/setters`), herança e polimorfismo.
- **`/03-estruturas-de-dados`**: Vetores (arrays), matrizes e coleções (`ArrayList`).
- **`/04-tratamento-de-excecoes`**: Controle de erros com `try-catch` e exceções.

---

### 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java (JDK 17+)
- **IDEs:** VS Code / Eclipse / IntelliJ IDEA
- **Versionamento:** Git & GitHub
